# Windows Integration 

## Release 3.8 distribution note

The primary Release 3.8 installer includes Windows 3.1/3.11 integration (`!W31.EXE`) only. `!W30.EXE` remains in the source tree for Windows 3.0 development/testing but is intentionally omitted from `INSTALL.DAT` until Windows 3.0 support is stable and can move to the planned second Windows disk.

## Clock button (3.772)

Launch `!W30.EXE /CLOCK` or `!W31.EXE /CLOCK` to replace the button title with a live clock formatted using Windows regional settings. Right-click Manage/Edit/Remove labels temporarily override it. See [3.772 release help](RELEASE.MD).
