## Flashing effects and Supersonic Mode (3.772)

Set `flashing=false` in `LAUNCH.CFG` to disable the Pop and Metro flash animations and Typo's new Supersonic effect. This is a configuration-only accessibility setting, with no UI control. The default is `flashing=true`. Restart a running game after editing it. See [3.772 release help](RELEASE.MD) for details.

With flashing enabled, Typo flashes the Panel bright white on each typing keypress above 70 WPM (temporary TC3 test threshold). The effect uses background intensity, not blinking text.
