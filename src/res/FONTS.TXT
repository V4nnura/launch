Launch! build font reference
============================

Source font files in this directory use the same names shown in the Launch!
Font menu wherever DOS 8.3 naming permits.  LAUNCHUI.FNT/F14 are internal UI
glyph resources rather than selectable fonts.

Standard remains font ID 0. Launch! intentionally remains font ID 6 on both
VGA and EGA so the factory FONT_ID=6 setting selects Launch! on either adapter.

!FONT.COM is the standalone font persistence TSR. It owns its own resident
PSP/MCB and receives live font updates from Launch! through its INT 2Fh service.
