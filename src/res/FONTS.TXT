Launch! build font reference
============================
VGA
---
FONT.DAT contains the built-in 8x16 VGA font catalogue.  VGA Font
configuration shows FONT.DAT plus any external APPDATA\*.FNT fonts.

EGA
---
FONT14.DAT contains only real 8x14 fonts supplied for EGA.  No 8x16
font is converted or synthesized for EGA.  EGA Font configuration shows
FONT14.DAT plus any external APPDATA\*.F14 fonts.

FONT14.DAT slot order (font ID):
  1 Humanist      HUMANIST.F14
  2 Neat          NEATSANS.F14
  3 Script        SCRIPT.F14
  4 Serif         SERIF.F14
  5 Serif Bold    SERIFB.F14
  6 Launch!       LAUNCH.F14
  7 Super         SUPER.F14

Standard remains font ID 0.  Launch! intentionally remains font ID 6 on
both VGA and EGA so the factory FONT_ID=6 setting selects Launch! on
either adapter.

!FONT.COM is the standalone font persistence TSR.  It owns its own resident
PSP/MCB and receives live font updates from !.EXE through its INT 2Fh service.
When Persist is enabled, !.EXE also writes FONT.CUR beside the suite; !FONT
reads that cache when it is loaded from AUTOEXEC.BAT and immediately applies
the selected font.  It retains both 8x16 VGA and 8x14 EGA fonts across
supported 80x25 mode sets.  Without !FONT resident, !.EXE still loads the
selected font transiently on every run.
